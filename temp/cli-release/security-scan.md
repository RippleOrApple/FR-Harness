**扫描日期：** 2026-08-01

## 范围

- 当前版本：全部受 Git 跟踪文件。
- 完整本地历史：`git rev-list --all` 可达的全部提交。
- 远程历史：`origin` 远程引用可达的全部提交。
- 类别：本机绝对路径、用户目录、常见 API Key / GitHub Token / Google Key、私钥头、作者与提交者邮箱。

扫描报告只记录类别与数量，不记录任何疑似秘密、邮箱正文或本机完整路径。

## 历史处置

历史路径命中来自旧课程过程证据。当前分支不重写历史，原因是历史重写会改变 `PLAN.md`、`SPEC_PROCESS.md` 和 `AGENT_LOG.md` 引用的提交哈希，并影响已合并 PR 与远程 main。最终提交及 Release 文件不包含这些路径。

如果课程或仓库所有者要求彻底清除既有远程历史，应在备份、通知协作者并轮换所有引用后，单独批准一次 `git filter-repo` 历史重写；该操作不应混入常规功能 PR。

## 结论

- 当前可发布树未发现本机绝对路径、个人目录、邮箱或真实秘密候选。
- 历史未发现常见凭据或私钥候选。
- 历史仍包含旧本机路径证据，已明确记录但未擅自破坏提交历史。
